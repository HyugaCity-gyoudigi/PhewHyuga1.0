# ヒュー！日向「世界でいちばん、休める街へ」ロゴ・イラスト集

## 概要

「ヒュー！日向」に関するロゴ・イラスト・ポスターなどの素材を、カテゴリ別に閲覧・ダウンロードするためのWebアプリです。

`list.csv` に記載されたカテゴリ名とファイル名をもとに、各カテゴリフォルダ内の画像・デザインデータを読み込みます。

## 主な機能

- CSVによる素材一覧の自動読み込み
- カテゴリ別の素材表示
- PNG・JPG画像のサムネイル表示
- サムネイル画像の拡大表示
- AI・PSD・画像ファイルのダウンロード
- RGB版・CMYK版の表示
- 画像が存在しない場合の代替表示
- 禁止事項画像の表示
- マニュアルPDFのダウンロード
- スマートフォン・タブレット画面への対応
- 読み込み完了時のファイル数・カード数・カテゴリ数の表示
